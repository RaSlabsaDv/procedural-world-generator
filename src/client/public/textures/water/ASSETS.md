# Ocean normal tile

waves-normal.png is an original deterministic periodic 128x128 RGB8 normal map,
generated by scripts/generate-water-normal.py using analytical derivatives of
64 periodic wave components with independent fixed-seed phases and balanced
perpendicular directions. This prevents the original three-wave striped pattern. Dedicated to CC0-1.0; no external source imagery.
It is scalar normal data (NoColorSpace), repeat wrapped with mipmaps and reused
for two scrolling samples. Regenerate with the standard-library script; do not
hand-edit it. Runtime geometry and terrain algorithms are unrelated to this asset.
