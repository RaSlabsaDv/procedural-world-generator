Original CC0-1.0 procedural RGB8 normal atlas, generated by
scripts/generate-terrain-normals.py using periodic quintic value fields
and analytical derivatives. No external source images or baked lighting.

128x640 pixels: five vertical 128-square layers Grass/Soil/Sand/Rock/Snow.
Seeds 1801..1805; frequencies 3/7/13/23; weights .08/.18/.34/.40 divided
by frequency for scalar heights. Derivative strengths 1.2/1/.7/2.2/.45.
Encode round(128+127*N); neutral RGB128/128/255 is exact.
Load as linear RGBA data into five separate array layers; repeat and mip
filter per layer to prevent atlas bleed. No bitmap editing dependency.
